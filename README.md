An entry for make.fun's [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) ($3 total, top 3 × $1): a tiny program that writes one original one-line office joke to `entry.txt`. A judge model compares the entries pairwise and crowns the line that gets the biggest laugh.

> I put 'excellent at multitasking' on my CV because I can attend a meeting, answer emails, and quietly quit all at once.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
cat ./output/entry.txt
```

Requires Node 22 or later. No network, no randomness — the output is the same every run.
